# Quick Task 260809-i1z: Description translation + bulleted summary (Wave C)

Add a description-translation + bulleted-summary card to shortlist detail.
Daniel reads Estonian slowly; kv.ee descriptions are dense Estonian text.
Give him: (1) raw original (collapsible), (2) Russian translation, (3)
AI-extracted bulleted key-facts summary — piggybacked onto the existing
`evaluate_listing` Claude call (no second API round-trip).

1. **Backend: migration 0005 + model columns** — add `description_ru` (TEXT

   add matching `Mapped` columns to `models.Listing`.

4. **Backend tests** — `backend/tests/test_ai_translation.py` covering

   VerdictBand and the checklist/finance grid.
