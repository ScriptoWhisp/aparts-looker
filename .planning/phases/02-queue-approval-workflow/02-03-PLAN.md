| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-XSS | Tampering | app/static/index.html Pending tab render | high | mitigate | Use textContent + createElement/appendChild ONLY inside the Pending tab code region — no innerHTML. Verified by an awk-scoped grep in Task 2 `<verify>`. |

| T-02-CSRF | Tampering | main.py POST endpoints | low | accept | Single-user personal tool behind Caddy basic auth; no third-party origins expected. CSRF token pattern would be over-engineering for the threat model (scale=1, no untrusted browser contexts). |
| T-02-SC | Tampering | npm/pip/cargo installs | high | mitigate | No new packages introduced in this plan — all endpoints use FastAPI + Pydantic + json (already in Phase 1 requirements.txt); no client-side npm additions. |
