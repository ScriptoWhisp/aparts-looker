    (a) `set_viewing_scheduled(listing_id: str, scheduled_at_iso: str) -> bool`:
        - Acquires `_lock` (RLock, re-entrant safe).
        - Loads app_data.
        - Finds entry in `data["properties"]` by id (per D-01: state lives on properties[] entries only).
        - Returns False if not found.
        - Sets `entry["status"] = "viewing_scheduled"` per D-01.
        - Sets `entry["scheduled_at"] = scheduled_at_iso` per D-02.
        - Appends `{"action": "scheduled", "at": <UTC now iso>, "scheduled_for": scheduled_at_iso}` to `entry.setdefault("viewing_history", [])` per D-04.
        - Calls `save_app_data(data)` and returns True.
        - Wraps everything in try/except Exception: return False per project never-raise convention.

    (b) `mark_viewed(listing_id: str) -> bool`:
        - Same shape as (a). Sets `entry["status"] = "viewed"` per D-03. Appends `{"action": "viewed", "at": <UTC now iso>}` to viewing_history.
        - Returns False if entry not found in properties[] or if current status is not "viewing_scheduled" (guard clause: mark_viewed is only valid FROM viewing_scheduled — enforces D-03's "no auto-transition" rule). Log a warning on invalid transitions and return False.

    (c) `save_negotiation_brief(listing_id: str, brief: dict) -> bool`:
        - Same shape as (a). Overwrites `entry["negotiation_brief"] = brief` per D-06 ("Every regeneration overwrites the field").
        - Also sets `entry["negotiation_brief_generated_at"] = <UTC now iso>` as a sibling field for freshness display (D-06 mentions brief_generated_at as a required tracked timestamp).

    (d) `save_ku_enrichment(listing_id: str, ku_auto: dict) -> bool`:
        - Same shape. Reads existing `entry.get("ku") or {}`, extracts `manual = existing.get("manual", "")` (Pitfall 7).
        - Writes `entry["ku"] = {"auto": ku_auto, "manual": manual, "looked_up_at": <UTC now iso>}`.
        - The `looked_up_at` field is required by D-13 ("Section header shows the `looked_up_at` timestamp").

    All four helpers use `from datetime import datetime, timezone`. If not already imported at module scope in data_store.py, add the import at the top of the module.

    Add module-docstring update noting the four new helpers and their D-XX references.
