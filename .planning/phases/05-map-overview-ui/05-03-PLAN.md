<objective>
Deliver the two data artifacts Plan 04 needs to render the district heat zone overlay: (1) a static GeoJSON file with all 8 Tallinn city district polygons under app/static/, and (2) a GET /api/districts endpoint that computes avg price/m² per district from properties[] + pending[]. The GeoJSON is generated once at build time by fetching Nominatim's polygon_geojson endpoint for the 8 known OSM relation IDs; it is not fetched at runtime. The API endpoint reads app_data on every request (no caching — data volume is single-user scale) and returns a JSON array keyed by district name.

Purpose: Plan 04's map.js needs both artifacts to colour each district polygon by its price quartile. Without the GeoJSON there is nothing to draw; without the API there is no data to colour by. This plan produces both without touching the map rendering itself.

Output: One committed static file (tallinn-districts.geojson), one new FastAPI endpoint, and a small pytest scaffold that guards the endpoint's response shape and avg computation.
</objective>

       - `prices = groups[name]["prices"]`
